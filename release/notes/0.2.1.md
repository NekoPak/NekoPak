NekoPak 0.2.1 预览版

## 登录与网络恢复

- 启动时从系统凭据库恢复登录状态，不再把临时无法刷新令牌当成未登录。真正被服务端拒绝的刷新令牌仍会过期。
- Android 返回前台或收到网络恢复事件时重建连接。临时 CDN 网络错误清理旧连接与解析缓存，适应 VPN / 直连切换。
- 下载临时断网后持续退避等待恢复，间隔最多 30 秒；服务端要求更长等待时遵守 Retry-After。保留已校验进度，手动暂停、取消与完整性错误仍停止。
- 黄色网络提示可以关闭，也可点击重新连接；关闭提示不会停止后台重试。

## 下载与测速

- 下载设置现支持同时下载任务 1–8、每任务连接 1–16；两项实际控制引擎并行度，并保存到本地。
- 设置修改应用于后续下载窗口；调低并发数时已发出的请求结束后收敛。并行任务共享带宽上限，分段下载仍核对范围、总长度与文件身份。
- `mypikpak.com`、`mypikpak.net`、`pikpak.me`、`pikpakdrive.com` 分别测量文件接口、复用连接和账号接口耗时，并显示失败状态。自动选择依据本轮可用结果；手动选择保留。
- 修复 Windows 原生界面解析测速字段错误导致没有结果。

## 升级和验证范围

Android ARM64，最低 Android 7.0 / API 24，versionCode 201，沿用既有签名，可覆盖升级；Windows 沿用原数据目录。0.1.4 / 0.2.0 可在应用内检查更新。

回归测试使用隔离 HTTP 服务、受控网络失败及浏览器 IPC 样例，覆盖离线会话恢复、刷新失败后恢复、并行范围与最终文件字节、设置持久化、网络提示关闭和重新连接。真实 PikPak 账号、实体手机 VPN 切换和真实下载带宽未在本环境验证。测速结果表示当次延迟和连通性，不表示下载速度。
