NekoPak 0.2.0 预览版

## 原生桌面

- Windows 客户端改用 Slint 原生界面，直接调用 Rust 核心，无需 WebView2；默认 GPU 渲染，无可用驱动时可回退到 CPU。
- 文件列表与网格、传输、登录与验证、多账号、设置、分享、同步、挂载和整理工具迁入原生界面；沿用原有数据目录与任务、设置。
- 新增图片查看器与媒体库、Windows 视频画面预览和片段起止标记、Ctrl+K 命令面板、F1 快捷键列表及文件拖放。
- 文件和传输模型按变化更新；Windows 排序使用预计算的系统排序键；窄窗口自动隐藏次要列。

## Android

- 传输卡片更紧凑，暂停、继续、重试与导出改为行内图标按钮；改善触控反馈、列表分隔线和照片墙。
- 语言包按需加载，简体中文不下载额外译文，减少首屏脚本。
- 保留 0.1.4 的后台传输：切后台或锁屏后可通过系统通知继续下载，也可在通知中全部暂停。系统回收、划掉应用或关闭该功能时持久暂停，返回后手动继续。

## 下载与升级

- Windows：x64，Windows 10 1709 或更新版本；提供安装器和便携 ZIP，不需要 WebView2。
- Android：ARM64，Android 7.0 / API 24 起，versionCode 200，沿用既有 APK 签名，可覆盖安装。
- 0.1.4 可从应用内检查本版更新；0.1.3 及更早版本读取旧仓库，需要手动安装一次。请勿为升级卸载 Android 应用，以免删除应用内数据。
- 发布包含两端签名清单、签名更新清单、构建报告和许可证。Windows 清单签名不等于 Authenticode 证书。

此版本仍为 Pre-alpha 预览。Windows 实体机上的托盘、自启动、拖放及预览观感、真实账号流程和 Android 实体机后台运行仍待人工验收。Android 普通上传与共享目录同步尚未完成；视频画面预览不含声音，完整播放使用外部播放器。Linux / macOS 暂无经过桌面验收的发行包。
