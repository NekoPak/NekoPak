# NekoPak 产品需求文档（PRD）

状态：v0.1 / 2026-11-07 · 供 Astra 与 Opus 5.5 使用

## 1. 项目定位

**NekoPak** 是社区独立开发的轻量 PikPak 桌面客户端。它以 Rust 核心、高可靠文件操作、可选择的授权接入后端为基础，逐步提供无缝同步与虚拟盘挂载功能。桌面版优先 Windows x64，随后 Linux x64/macOS。

### 用户价值

- 用统一的现代化 UI 浏览、搜索、移动、管理云盘文件；拒绝套壳官方网页。
- 在免费及 Premium 账号的实际权限内进行上传、下载、离线任务与查看配额。
- 稳定进行大文件、多任务和弱网断点续传；失败可解释，可恢复。
- 按需将云盘映射到同步文件夹，进阶支持虚拟盘符；自动同步需具备可审计、安全预览机制。
- 低资源占用，无繁重的 Java 运行时与内置浏览器内核，媒体播放默认走系统/外部播放器。

## 2. MVP、后续版本和明确不做的内容

| 等级 | 需求 | 验收标准 |
|---|---|---|
| P0 | 授权会话/账号管理 | 可安全登录、退出、恢复会话、处理过期，绝不在日志显示密钥 |
| P0 | 云盘目录浏览、分页、搜索、文件元数据 | 1 万项规模无崩溃；列表虚拟化；可复制文件路径 |
| P0 | 基本文件操作 | 新建文件夹、重命名、移动、复制、回收站；删除前二次确认 |
| P0 | 创建/查询云下载任务 | 支持磁力链和 URL（仅在当前后端真正支持时展示） |
| P0 | 下载器 | 进度、速度、暂停/继续、取消、失败重试、分段与文件完整性校验 |
| P0 | 状态持久化 | 异常结束、断电模拟后恢复，不得丢任务、不静默清空 |
| P0 | 配额与错误可视化 | 显示免费/会员功能及后端的权限不足、限额、网络故障等原因 |
| P0 | 项目说明/致谢 | README、NOTICE 和源码引用位置都准确注明所有参考与复用 |
| P1 | 单向自动同步 | 本地→云、云→本地；差异预览、过滤器、删除默认关闭 |
| P1 | 双向同步 | 增量索引、版本判断、冲突副本、日志、保护性删除流程 |
| P1 | Windows Cloud Files 同步根目录 | 占位文件与按需下载，失败可回滚；**不保证是独立盘符** |
| P1 | 外部播放器 | 打开经过授权的流媒体链接，断链时可重试 |
| P2 | Windows 真实虚拟盘符 | WinFsp 可选、只读先行、随机读取/缓存/权限与锁语义正确 |
| P2 | Linux FUSE 挂载 | 仅在 Linux 目标平台完成测试后发布 |
| P2 | WebDAV 与 Rclone 可选适配 | 能力检测，要求用户自行配置/安装（不额外捆绑） |
| P2 | 多账户/分享/媒体库 | 单独评审权限、配额和状态一致性后推进 |

**非目标：** 不以规避 PikPak 配额、地域限制、反滥用机制为产品目标；不伪称官方授权；不把独立 WebDAV、Rclone、播放器、WinFsp、全部 CLI 实现一股脑打包；不默认开启双向同步或自动删除；不在首版实现 Android/iOS。

## 3. 关键使用流程

1. **首次打开：** 展示独立客户端声明 → 检测可用后端 → 提供安全授权方式 → 展示账号类型与配额状态 → 文件列表。
2. **发起云下载：** 用户输入磁力链/URL → 校验与预览 → 选目录 → 创建任务 → 查看远端进度或精确错误；绝不把“提交成功”误称“下载完成”。
3. **下载本地文件：** 用户选目标 → 创建持久任务 → `.part` 文件 + identity 元数据 → 分段请求与验证 → 完成后原子重命名，保留校验失败现场。
4. **单向同步：** 选择源/目标和规则 → dry-run 展示新增/更新/潜在删除 → 用户明确确认 → 原子提交清单 → 安全执行。
5. **双向同步：** 建立同步基线快照；基于上次状态、远端 ID/hash/mtime（如可用）和本地信息做三方比较。冲突保留两份，不默认最后写入覆盖。
6. **虚拟盘：** 用户显式安装并允许文件系统依赖 → 检测后端 `read_range` 能力 → 挂载只读 → 缓存索引/随机读取 → 写入能力后续单独放开。

## 4. 账号、配额与后端选择

- 以用户**明确授权**的能力为准；不得因 Premium/Free 猜测某接口一定可用。
- 官方 CLI 作为可选后端时，需要检查可执行文件、版本、协议/输出是否可机器解析；**不要默认捆绑**未确认可再分发的软件。
- 社区 Rust 接口适配器需明确提示是“非官方兼容层”，以隔离接口变更风险。
- PikPak Connected Apps 的云下载、下行、上传分别共享各维度月度配额的 25%；免费账号 Connected Apps 每日下行还受 5 GB 限制；配额耗尽不由后端切换重置。
- 回退条件：`UnsupportedOperation`、可恢复的后端故障、经授权的能力缺失；不对 `QuotaExceeded`、`AccountRestricted`、`AuthExpired`、`NotFound` 做盲目回退，避免重复计费和重复副作用。

## 5. 交付定义

- 每个阶段至少包含：可运行可验证程序、测试报告、体积与内存基线、版本变更、依赖许可证清单。
- 前端所有操作必须对接真实 Tauri 命令或 Mock；不允许“好看的假按钮”。
- 最小版不满足 `≤5 MiB` 时必须报告构成与权衡，不得删除数据校验/身份验证/TLS 来造数字。
- 任何新网络兼容功能须默认关闭、明确告知影响范围、可撤销、可测试，不自动改动全局 Hosts。
