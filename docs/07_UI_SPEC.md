# NekoPak UI / UX 设计规范（Opus 5.5）

产品感觉：**干净、轻快、克制、有辨识度**。适度使用猫系命名/图标，但不要大面积卡通化；不做廉价玻璃拟态、炫光渐变、重动效、全套 Material/Ant Design 套件。

## 1. 布局与信息架构

推荐 Windows 桌面布局（响应式最小窗口时收起栏位）：

```text
┌───────────────────────────────────────────────────────────────────────┐
│ NekoPak   [搜索文件...                    ] [账号] [设置] [最小化/关闭]│
├───────────────┬───────────────────────────────────────────────────────┤
│ [云盘]        │  我的文件 / 项目 / 资料                         [↻] │
│ [最近]        │  [新建] [上传] [新建云下载] [下载] [视图] [排序]      │
│ [传输]        │  ---------------------------------------------------  │
│ [云下载]      │  □  名称                    大小       修改时间     │
│ [自动同步]    │  □  文件夹 A                    —       ...         │
│ [挂载]        │  □  片段.mp4                 1.4 GB      ...         │
│ [回收站]      │                                                       │
│               │                                                       │
│               │                                                       │
├───────────────┴───────────────────────────────────────────────────────┤
│ 账号状态 · 当前任务 2 · 配额: 按实际接口查询       │
└───────────────────────────────────────────────────────────────────────┘
```

统一操作入口：文件列表右键菜单、顶部工具栏、拖拽上传（先校验权限）；批量操作展示目标数量及不可撤销操作的确认。

## 2. 页面状态与行为

| 页面 | 必要功能 | 最容易遗漏的状态 |
|---|---|---|
| 首次启动 | 原生账号密码登录、可用能力 | 尚未接入、验证码、登录取消、网络失败 |
| 文件浏览 | 虚拟滚动、面包屑、搜索、排序、复制/移动、回收站 | 分页、空目录、10K 文件、权限不足 |
| 任务中心 | 下载/上传/云下载分组、速率、进度、暂停/恢复/取消 | 离线恢复、校验中、重试等待、配额限制 |
| 自动同步 | 本地/远端目录选择、过滤、方向、执行计划预览 | 无权读取、冲突、扫描不全、远端空响应 |
| 设备挂载 | 设备环境检测、只读/只缓存、已安装依赖、手动卸载 | 未装 WinFsp、无 read_range 能力、网络断开 |
| 设置 | 后端检测、账户、缓存、带宽、日志、主题、实验功能 | 不可用选项禁用原因、危险操作确认 |
| 致谢/关于 | 开源项目来源、许可证、版本、反馈入口 | 官网/上游链接、非官方声明 |

## 3. 设计令牌建议（可修改但需一致）

- 视觉：低饱和中性色 + 一种温和蓝绿/青色强调色；亮色/暗色各自调校对比度。
- 字体：系统 UI 字体栈；Windows 优先 Segoe UI，跨语言正常 fallback；不嵌入庞大可商用性不明的字体文件。
- 间距：4px 基线；常用 `8/12/16/20/24`，圆角 8–12px，边框弱化分隔、避免重阴影。
- 状态：成功、警告、错误不仅靠颜色；配额错误明确写文字解释，按钮提供解决方法。
- 动画：150–200ms 小幅反馈；用户关闭动画时尊重 `prefers-reduced-motion`；不影响滚动性能。
- 图标：统一 16–20px 线性图标，可用轻量 SVG 集，不捆打整套图标字体。

## 4. 桌面交互要求

- 文件双击打开文件夹/启动预览；`Ctrl+F` 搜索、`F2` 重命名、`Delete` 移至回收站、`Ctrl+C` 复制路径或按语境复制文件；所有快捷键在帮助中列出。
- 右键菜单要支持键盘访问；文件列表与虚拟滚动保持焦点、选中状态和排序稳定。
- 带宽、配额和进度必须来自实际后端事件；未知则显示“未提供”，绝不编造百分比。
- Free/Premium 等级以实际查询为准；未知等级不默认显示 Free。产品界面不展示后端选择或安装 CLI 指引。
- 配额耗尽时仍保留文件列表和任务历史，允许用户跳转官方应用；不得提供“切换后端重置额度”操作。
- 高级网络兼容开关位于设置底部，默认关闭，需清楚展示可影响的 NekoPak 请求；不能暗中修改系统 Hosts。

## 5. 前端技术约束

- 默认 `TypeScript + Vite + CSS`；若 React 组件化能显著提高维护性可使用 React，但不要叠加多套状态管理/UI 框架。
- 文件列表大于 5K 使用虚拟滚动；所有服务数据通过类型安全的 `api.ts` + mock adapters 获取。
- 任务进度通过 Tauri 事件驱动，启动时必须读取快照，避免事件丢失造成 UI 错误。
- 页面禁用态与错误态必须存在；不可只有截图级静态 UI。
- SVG/PNG 资源、第三方图标依赖/许可应进入 `THIRD_PARTY_NOTICES.md`。
- 对大文件数字、名称、Unicode、多语言排版进行测试。NekoPak 英文产品名固定，不要变成 PikPak 官方商标。

## 6. 交付验收

2026-11-10 手机验收修正：手机组件树必须使用文件／传输／我的底部导航，文件类型图标、
单击打开与长按多选，操作放底部单；设置为子页。不能以桌面侧栏改抽屉、隐藏列或无横向
溢出作为手机适配完成。传输卡片应能读到字节进度和实际速度，终态记录可移除。至少对
360/390/412px明暗主题检查文件、传输、我的、设置、登录和操作单，并实测APK启动图标。

新增硬要求：前端不能以当前 API 切片能力缩减最终上游功能清单。片段入口支持视频预览、
起止时间/微调、原画与表示选择、关键帧对齐提示、字幕/音轨损失说明、空间/时长估算、
任务进度与取消恢复。来源无可读能力时解释原因；未注册的后端片段命令保持禁用。
原画和转码不可静默互换；不得把字节分块下载称为“指定视频片段下载”。
完整范围见 UPSTREAM_PARITY.md；目前本地实验库不等于可用的产品片段入口。

- Mock 下完成全页面交互验证（至少包括 AuthExpired/QuotaExceeded/NotFound/TransientNetwork）。
- Windows 125%/150% 缩放不溢出；1280×720 可用，100%/200% 下可读。
- 亮色/暗色均无高对比度不可见文字；Tab 键可遍历主要控件。
- 最终前端 build 的静态资源 KB 统计，说明引入每项体积较大的依赖原因。
- 输出实际截图、UI 改动说明与 IPC 契约差异。禁止把占位按钮宣传为已经完成的能力。
