# 功能对照：Piko → NekoPak

核对日期：2026-11-08　Piko 版本：`NihilDigit/piko@d0bd8fe`（README 与公开截图，**只作功能和设计参考，没有复制代码**）

状态说明：

- **已做**：界面、交互和演示数据都已完成，单元测试或 E2E 覆盖。接口就绪后，桌面版可以直接使用。
- **等后端**：界面已经完成；桌面版要等 Astra 实现对应命令。命令与 PikPak 接口的对应关系见 `docs/BACKEND_API_ADAPTER.md` §4。后端未实现时，按钮禁用并显示“暂不支持”。
- **待实现**：保留在最终功能对齐目标中，本次不等于完成。
